
# Arduino Mini Projects

## Projects
- LCD_Project:
   LCD에 텍스트 출력 연습 (LiquidCrystal)
  
- passivebuzzer_Project:
  수동 부저의 작동방법 테스트
  
- obstacle_alert_system:
  Measures distance using an ultrasonic sensor and alerts with a buzzer
  The buzzer beeps more frequently as an object gets closer
  Sensor used: HC-SR04
  
- LED State Machine (C)

This project implements a simple LED controller
using the State Machine design pattern.

## States
- OFF
- ON
- BLINK

## Purpose
To practice enum, switch-case logic,
and structured program design in C.
